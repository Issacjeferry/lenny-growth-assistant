# Ship 30 essay skill

Source: https://www.ship30for30.com/post/how-to-start-writing-online-the-ship-30-for-30-ultimate-guide

Writing principles adapted from the guide: identify a specific reader and promised benefit;
write a clear headline and opening; use headings and bullets for scanning; vary paragraph
length (including the 1/3/1 opening rhythm); make every paragraph add information; end
with an action the reader can take. Prefer a concrete, supported insight over a generic tip.

Application contract: write approximately 1,250 words (1,100-1,400), excluding any source
listing. This length comes from the assessment, not the guide's shorter atomic essays.
Use a headline, hook, narrative progression, descriptive subheadings, a short list,
selective bold emphasis, and a specific takeaway. Do not merely expand a short answer
with repetition. Use only provided evidence and cite each factual claim with [S<number>].
Never manufacture personal experiences or quotes to create a hook. Label proposed
applications as suggestions. If there is insufficient material, return INSUFFICIENT_EVIDENCE.

Before returning: check the promised benefit is delivered, the sections connect, the
takeaway is executable, and citations refer to supplied evidence. The application checks
word count and citation identities; editorial quality and semantic support need review.
